# My project's introduction
In my diverse portfolio of projects, I have applied a range of technologies and methodologies across various domains. I adopted SQL for efficient database design and retrieval, and leveraged R for comprehensive data wrangling tasks, including handling structured and text-based datasets. I supported strategic business decisions by building a business case for a car rental firm and applied Kanban methodology to develop Personas, User Stories, and Acceptance Criteria using Miro. To generate actionable insights, I created Power BI dashboards aligned with organizational goals and deployed self-service analytics solutions in emerging industry segments such as Nutraceuticals, Cosmeceuticals, and Nutricosmetics.

In data visualization, I employed Tableau and SAS Viya to present insights for sectors such as banking and sports, as well as customer segmentation. Descriptive analytics with Excel were used to solve real estate challenges, while predictive analytics models using R, Python, and SAS Enterprise Miner tackled car sales, customer segmentation, and association rule mining problems.

My work further involved developing decision trees and classification models, chatbot applications in Dialogflow CX, comment and image classification using Python and LLMs, as well as Azure cost analysis and automation.

In 2024–2025, I expanded into AI and cloud analytics by working with Prolog, developing intelligent inventory forecasting models, building real-time Power BI dashboards, and applying NLP for sentiment analysis, classification, and fake news detection using deep learning models. I also designed full-scale AI-based solutions for retail, inventory management, and sustainability analytics using tools like Google Colab, TensorFlow, Databricks, and Streamlit.
